# ZeekFusion MC menu

The MC route is a game-menu experience below the shared website navbar. Back to ZeekFusion.com also returns to the homepage. The menu fills the available viewport below the navbar. Join Server, Java, Bedrock, instructions and Server Info are separate URL-addressable menu screens. Browser history and Escape/Back navigation are supported. The existing IP addresses, version, Discord link and access process are retained.

Menu sounds are synthesized locally with Web Audio and off by default. There is no autoplay audio, tracking or external font request. The panorama and splash animations respect reduced motion. The pixel font is Press Start 2P, distributed with its SIL Open Font License under public/fonts.

## Background asset

Built-in image-generation tool, stylized-concept mode. Final asset: `public/images/mc-menu-panorama.png`.

Final prompt: “Use case: stylized-concept. Asset type: full-screen background for a nostalgic Minecraft-inspired main-menu website. Create an original wide 16:9 panoramic voxel landscape reminiscent of early Minecraft beta terrain, NOT a UI mockup. View from a grassy block hillside across a blue lake and winding river, blocky green oak and birch trees at the sides, stepped dirt and grass cliffs, distant chunky mountains, soft square clouds in a warm pale blue sunset sky. Authentic low-resolution pixel textures mapped onto cubes, simple old game lighting, charming nostalgic atmosphere, no glossy realism or modern shader reflections. Composition: horizon upper third, interesting landscape across whole width; center relatively calm for a menu overlay. Warm afternoon amber sun at upper right. No characters, no buildings required, no text, no logos, no buttons, no UI. This is only the background artwork. Output wide landscape.”
